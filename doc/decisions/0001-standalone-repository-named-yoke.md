# 0001 — Standalone repository named yoke

Date: 2026-08-08. Status: accepted.

The USB/HDMI-mesh effort becomes its own repository, `~/git/claude/yoke`,
a sibling of telos. The request described "beginnings" of this project
under `./telos`; a full search of telos (decisions, design documents,
research, site, git history, all branches) and telos-private found no
such material, so this repository starts fresh and nothing was moved out
of telos. If those beginnings exist elsewhere, they should be reconciled
into this repository when found.

The name **yoke**: to yoke is to pair two things so they work together —
exactly the system's one operation, pairing a producer to a consumer.
Four letters, pronounceable, works as a CLI verb (`yoke pair a b`).
