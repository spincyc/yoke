# Yoke documentation

The [USB hardware](../usb.md) uses two Radxa ZERO 3E boxes: one beside
the USB device and one connected by USB to your computer. Read the
[USB design](../../../doc/design/USB-ENDPOINT.md) for the hardware and
remaining firmware work, or [run the software tests](../start.md) without
boards.
